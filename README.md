# 📊 Telecom Customer Churn Analysis

## Introduction

An interactive **Telecom Customer Churn Analysis** project built using **Power BI and SQL** to identify customer churn patterns, understand high-risk customer segments, and generate actionable retention insights.

## Dataset & Tools

**Dataset:** Telecom customer data containing demographics, services, contracts, tenure, payment methods, and churn information.

**Tools:** Power BI | DAX | SQL | Data Cleaning | Data Modeling | Data Visualization

## Key KPIs

* 👥 **Total Customers:** ~7K
* ❌ **Churned Customers:** ~2K
* 📉 **Overall Churn Rate:** **26.54%**
* 💰 **Monthly Revenue:** **456.12K**

## Key Insights

* **Month-to-month customers** have the highest churn rate (**42.71%**), compared with **2.83%** for two-year contracts.
* Customers with **0–12 months tenure** show the highest churn (**47.44%**).
* **Electronic Check** customers have the highest payment-method churn rate (**45.29%**).
* **Fiber Optic** customers show higher churn than other internet-service groups.
* Customers without **Online Security (41.77%)** and **Tech Support (41.64%)** show substantially higher churn.
* Customers **without partners (32.96%)** show higher churn than customers with partners (19.66%).

## Key Recommendations

1. Strengthen **onboarding and engagement** for new customers, especially during the first 12 months.
2. Develop **retention offers and loyalty plans** for month-to-month customers.
3. Investigate billing/payment experience among **Electronic Check** users.
4. Promote **Online Security and Tech Support** services to improve customer engagement and retention.
5. Investigate the causes of higher churn among **Fiber Optic customers**, including pricing, service quality, and support experience.

## Conclusion

The analysis identifies **tenure, contract type, payment method, internet service, and support services** as important dimensions for understanding churn. The Power BI dashboard enables interactive exploration of these segments and can support more targeted, data-driven customer retention strategies.
